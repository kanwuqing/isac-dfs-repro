# OFDM 蜂窝网络无设备感知复现研究报告

**对象论文**: Q. Shi, L. Liu, S. Zhang, S. Cui, "Device-Free Sensing in OFDM Cellular Network," *IEEE Journal on Selected Areas in Communications*, vol. 40, no. 6, pp. 1838–1853, Jun. 2022.

**本文档地位**: 本项目唯一的研究报告, 涵盖环境配置, 运行说明, 实现代码, 实验结果, 关键指标, 参数表, 可视化图像与误差分析. 全部数值取自 `results/data/` 下的 CSV 文件与代码实际运行输出, 可逐项核对.

## 摘要

本文复现了上述论文提出的两阶段无设备感知框架. 该框架从基站接收到的 OFDM 信号出发, 先估计目标到各基站的距离, 再将各基站获得的无标签距离集合组装为目标位置. 复现工作包含两个部分: 一是按论文公式自行实现信号级的第一阶段 (论文官方代码未提供), 二是复现论文第二阶段的数据关联与定位算法.

实验在 300 次蒙特卡洛几何, 随机种子 20240929 的条件下进行, 得到三项主要结果. 其一, 定位精度随带宽提升而单调改善: 带宽由 10 MHz 增至 400 MHz 时, 误差概率由 94.11% 降至 0.33%, 剔除误关联样本后的均方根误差由 15.77 m 降至 0.24 m. 其二, 目标数在 2 至 7 之间变化时, 误差概率始终低于 5%, 说明数据关联并非该框架的根本性限制. 其三, 在 4500 个几何样本中未观察到鬼影目标, 单组 95% 置信上界为 0.01.

上述结论与论文趋势吻合. 本复现未与论文正式发表的数值表格逐点对齐, 且全流程运行于高信噪比条件, 未进行信噪比扫描.

## 一, 研究背景与复现目标

### 1.1 问题设定

无设备感知指在不给目标佩戴任何设备的前提下, 利用无线信号推断目标的位置. 论文考虑的载体是蜂窝网络中的 OFDM 下行信号: 基站发射已知的导频, 信号经目标反射后回到基站, 基站从回波中提取距离信息.

设系统中有 M 个基站, K 个目标. 基站与目标之间构成 M×K 条传播路径. 对第 m 个基站而言, 它在每个 OFDM 符号上接收到的信号, 等价于 K 条路径的叠加, 每条路径对应一个时延, 时延正比于该路径的往返距离.

难点在于接收端只能获得一组距离数值, 无法直接知道"哪个距离属于哪个目标". 这一标签缺失构成了数据关联问题, 也是论文第二阶段的核心.

### 1.2 两阶段框架

论文将问题拆为两个阶段.

**第一阶段 (测距)**: 每个基站独立处理自己的接收信号, 输出一个包含 K 个距离数值的集合. 该集合有序但无标签.

**第二阶段 (定位与关联)**: 利用各基站距离集合之间的几何约束, 将 M 个集合中的距离配对成 K 个目标, 并解出各目标坐标.

两阶段之间的接口是"M 个大小为 K 的无标签距离集合".

### 1.3 复现目标与官方代码状况

官方发布的 MATLAB 代码包共 6 个文件: `model.m`, `coorest.m`, `initial_est.m`, `diffdist.m`, `distsum.m`, `munkres.m`, 归档于本项目 `reference/official_matlab/` 目录.

该代码包**没有 `main.m`**, 也**没有信号级的第一阶段**. `model.m` 中直接以如下语句生成"测距结果":

```matlab
dist_m(m,k) = ceil(dist_r(m,k)/delta_d)*delta_d - delta_d/2;
```

即将真实距离量化到距离单元中点, 直接当作第一阶段的输出. 换言之, 第一阶段在官方代码中被整体假设掉了.

因此本复现的工作分为两部分, 性质不同:

| 部分 | 内容 | 性质 |
|---|---|---|
| 第二阶段 | 鬼影检测, 数据关联, 定位精修 | **复现**论文算法 |
| 第一阶段 | OFDM 信道估计, 抽头检测, 距离换算 | **实现**论文公式 (官方未提供代码) |

本项目设定的具体目标为:

1. 补齐信号级第一阶段, 使两阶段框架可以端到端运行;
2. 复现论文的四项核心结论 (带宽增益, 目标数影响, 鬼影可忽略, 关联非瓶颈);
3. 对关键算法环节与暴力解法做交叉验证, 确认实现正确;
4. 报告误差来源与建模假设的影响.

## 三, 运行说明

### 3.1 最短路径

依次执行以下四条命令即可从零得到全部结果与图像.

```bash
# 第一步: 环境自检, 不产生文件
python scripts/smoke_test.py
python scripts/smoke_test_phase2.py

# 第二步: 运行全部实验, 约 9 至 15 分钟
python scripts/run_experiments.py --exp all --trials 300

# 第三步: 生成图像
python scripts/make_figures.py
```

第二步向 `results/data/` 写入 5 个 CSV 文件与 1 个 `manifest.json`; 第三步从 CSV 读取数据, 向 `results/figures/` 写入图像.

### 3.2 命令行参数

`run_experiments.py` 支持三个参数.

| 参数 | 取值 | 作用 |
|---|---|---|
| `--exp` | `all` 或 `E1`…`E5` | 指定运行哪些实验 |
| `--trials` | 整数, 默认 300 | 每个参数点的蒙特卡洛几何数 |
| `--tag` | 字符串, 默认空 | 输出文件名后缀 |

示例:

```bash
python scripts/run_experiments.py --exp E2 --trials 50      # 带宽扫描, 缩减样本
python scripts/run_experiments.py --exp E3 --tag _try       # 输出写入 e3_..._try.csv
```

### 3.3 数据覆盖保护

脚本中设有一项保护机制: 当 `--trials` 小于 300 且未指定 `--tag` 时, 程序拒绝写入已有 CSV 文件并抛出错误.

```
拒绝写入 e1_error_prob_vs_K.csv: 当前只跑 3 次, 正式结果是 300 次.
小样本试跑请加 --tag _try 之类的后缀.
```

小样本试跑需加 `--tag`. 需要快速试跑时应显式指定后缀.

### 3.4 验证脚本

除主实验外, 以下脚本用于交叉验证关键算法环节.

```bash
python scripts/run_verify_all.py          # 批量运行四个验证脚本
python scripts/run_verify_all.py --fast   # 只跑前两个, 更快

python scripts/check_style.py             # 代码注释风格检查
```

`run_verify_all.py` 按由快到慢的顺序调用 `verify_ghost_positive.py`, `verify_ghost.py`, `verify_enum_strict.py`, `verify_enum.py`, 记录每个脚本的开始时间, 结束时间, 返回码与完整输出, 写入 `logs/verify_all_<时间戳>.log` 并同步打印到终端. 四个脚本全部返回 0 时退出码为 0; 有失败或超时则为 1. 单个脚本的超时上限为 1800 秒, 超时记为"超时"并继续执行后续脚本.

`verify_ghost_positive.py` 包含负控制和正控制: 负控制排除误报, 正控制确认检出能力; E3 的零结果需要两者都通过. 详见第六节.

各脚本单独运行的方式:

```bash
python scripts/verify_enum.py --max-k 3   # 剪枝枚举与暴力穷举的候选与目标值比对
python scripts/verify_enum_strict.py      # 严格版, 要求候选集合完全相同
python scripts/verify_ghost.py            # 高效鬼影检测器与暴力置换枚举比对
python scripts/verify_ghost_positive.py   # 正控制与负控制实验
```

`verify_enum.py` 不带参数时穷举至 K=5, 耗时较长; 日常验证建议加 `--max-k 3`.

### 3.5 可复现性

全部实验的随机种子固定为 20240929, 各实验网格点的种子按确定性规则派生 (见 4.6 节). 两次从空目录重新运行, 生成的 CSV 逐字节一致, 仅 `manifest.json` 中的耗时与时间戳字段不同.

`results/data/manifest.json` 记录了每次运行的解释器版本, 依赖版本, 各实验的逐点结果与总耗时, 可作为运行凭证.

### 4.2 波形与系统参数

| 参数名 | 符号 | 取值 | 说明 |

| `n_bs` | M | 4 (E3 另测 3 与 6) | 基站数 |

**仿真区域**: R = 240 m, 与论文 `model.m` 一致. 区域对角线长 R√2 ≈ 339.41 m, 这是区域内任意两点的最大距离.

### 4.3 第一阶段估计器参数

对应 `phase1_range_estimation` 函数.

| 参数 | 取值 | 含义 |
|---|---|---|
| `pfa` | 1e-6 (E4) / 1e-3 (默认) | 恒虚警率, 决定检测阈值 |
| `path_loss_exponent` | 1.0 (默认) / 2.0 (E5 消融) | 反射幅度按 d 的负幂衰减 |
| `include_cross_paths` | False (默认) / True (E5 消融) | 是否引入跨站反射路径 |
| `dynamic_range_compensation` | True | 用基站与目标的平均距离归一化信道增益, 使不同几何可比 |

**最小二乘估计闭式解** (`ls_channel_estimate_fast`):

```
ĥ = (1/(N·√p)) · Gᴴ · (conj(s) ⊙ ȳ)
```

其中 G 为傅里叶字典, G[n,l] = e^(−j2π(n−1)(l−1)/N). 该式的成立依据是 G 的列向量两两正交, 即 GᴴG = N·I. 已数值验证非对角元素不超过 8e−11, 故该式与显式伪逆解法在同一浮点精度下等价 (L 取 64, 227, 512 时, 两法输出最大差均为 0.000e+00).

**检测阈值**: σ²_h = σ²/(N·p), γ = σ²_h·ln(1/pfa). 每个基站最多保留 K 个能量最强的抽头, 对应论文"每个 h_{m,m} 含 K 个非零元"的可分辨性假设.

### 4.4 带宽与抽头数的对应关系

抽头序号由**往返**路径长度 2d 决定, 因此 L 个抽头能够表示的最大往返距离为 L·c₀/B; 换算为**单程**距离则为

```
d_max = min(L, Q) · c₀ / (2B)
```

区域内最长的单程距离为对角线 R√2 = 339.41 m.

L 的自动取值为 ⌈2·R√2·B/c₀⌉ + 2, 即恰好使整个区域不产生混叠.

| B (MHz) | Δd = c₀/(4B) (m) | L | Q | 单程 d_max (m) | 实际最大抽头序号 | 覆盖 339.41 m |
|---|---|---|---|---|---|---|
| 10 | 7.4948 | 64 | 2048 | 959.34 | 23 | 是 |
| 20 | 3.7474 | 64 | 2048 | 479.67 | 46 | 是 |
| 50 | 1.4990 | 116 | 2048 | 347.76 | 114 | 是 |
| 100 | 0.7495 | 229 | 2048 | 343.26 | 227 | 是 |
| 200 | 0.3747 | 455 | 2048 | 341.01 | 453 | 是 |
| 400 | 0.1874 | 908 | 2048 | 340.26 | 906 | 是 |

关键校验项为末两列的对比: 实际最大抽头序号始终小于 L (227 < 229, 453 < 455, 906 < 908), 未发生饱和.

若抽头序号被截断至 L, 远端目标会混叠进最后一个距离单元, 而混叠后的距离数值可能反而落回 d_max 以内, 此时仅凭"距离不超过 d_max"这一条件无法识别. 几何合法性实际上由"抽头序号小于 L"这一条保证, 上表已验证全部六档带宽均成立.

50 MHz 一档的 L = 116 是由区域无混叠约束决定的, 并非受 64 这个下限钳制. 复跑时若在任一带宽观察到异常远的定位点, 应优先检查抽头序号是否逼近 L.

### 4.7 两处需要主动说明的建模选择

**其一, 路径损耗指数取 1 而非自由空间的 2.**

论文未给出基站与目标之间的反射系数模型, 仅要求"K 条路径可分辨". 若取自由空间的 α = 2, 同一基站内近目标的反射强度会比远目标高出约 100 倍, 远目标必然低于任何合理的检测阈值, 这反而违反了论文自身的可分辨性假设. 因此默认取 α = 1, 此时单基站内动态范围约 10 至 20 倍. α = 2 作为消融实验在 E5 中给出, 精确恢复率由 1.00 降至 0.76.

**其二, 抽头数 L 按带宽自适应, 而非固定值.**

论文给出 R = 240 m, 但未公布 N, L, Q 的具体取值. 若 L 取得过小, 远端目标会混叠到错误的距离单元, 表现为一个来源不明的精度天花板. 官方 `model.m` 不涉及抽头计算, 故从未遇到此问题; 信号级复现必须显式处理. 4.4 节表格给出了每档带宽的 L 取值与覆盖校验.

## 五, 方法与代码实现

本节说明两个阶段的算法与代码结构. 源码位于 `src/isac_dfs/` 目录, 正文中给出对应的函数名.

### 5.1 第一阶段的代码结构

文件 `src/isac_dfs/phase1_range.py`, 共 364 行, 主要接口如下.

| 函数 | 作用 |
|---|---|
| `OFDMConfig` | 波形参数容器, 带宽与距离刻度由属性计算 |

### 5.2 最小二乘估计的简化

标准最小二乘信道估计需要求解

```
ĥ = (GᴴG)⁻¹ Gᴴ (conj(s) ⊙ ȳ)
```

其中 GᴴG 的求逆代价为 O(L²N).

由于 G 为傅里叶字典, 其列向量两两正交, 满足 GᴴG = N·I, 而单位阵的逆即 1/N 倍单位阵, 整个求逆过程可以约去, 只剩

```
ĥ = (1/(N·√p)) · Gᴴ · (conj(s) ⊙ ȳ)
```

此时计算量降至 O(NL), 相当于一次逆傅里叶变换.

这一简化是**精确的, 而非近似**. 验证方式是将其与显式求逆的结果逐元素比对: L 取 64, 227, 512 三种规模时, 最大差值均为 0.000e+00. 运行时间方面, L = 512 时实测提速约 500 倍, 具体倍数随 L 增大而增大.

### 5.3 抽头检测

对每个抽头计算能量 |ĥ_l|², 与阈值 γ 比较, 超过阈值者判为非零抽头.

阈值取 γ = σ²_h·ln(1/pfa), 其中 σ²_h = σ²/(N·p) 为单个抽头的噪声功率. 这一构造使得纯噪声被误判为目标的概率恰为 pfa, 与噪声强度无关.

检测完成后, 若抽头数超过 K, 保留能量最强的 K 个; 若一个也没有检出, 则兜底取能量最强的 K 个.

### 5.4 距离换算

抽头序号 l 对应的单程距离取该单元中点:

```
d̄ = (l − 1)·c₀/(2B) + c₀/(4B)
```

取中点是因为目标真实距离在单元内均匀分布, 取中点使最大误差最小. 由此产生的误差上界为

```
|d̄ − d| ≤ Δd = c₀/(4B)
```

这即是论文给出的量化界, 也是全部定位精度的理论下限.

### 5.6 位置精修

对应官方 `coorest.m`. 给定一组距离与基站坐标, 从线性三边定位的闭式解出发, 按阻尼牛顿方向迭代:

```
β ← β − λ · (JᵀJ)⁻¹ Jᵀr
```

其中 J 为残差对坐标的雅可比矩阵, r 为残差向量, λ = 0.2. 当步长范数小于 0.05 m 或达到 50 次迭代时停止.

由于 JᵀJ 只有 2×2, 正规方程采用显式闭式求逆, 几何接近降秩时加入对角阻尼. 对 2×2 系统而言这与伪逆等价, 但速度更快, 因为最大似然算法会调用该函数数百次.

### 5.7 鬼影目标检测

对应论文 Sec. V, 适用于测距完美 (无误差) 的情形.

判定原理为圆交汇一致性: 一个候选关联是一致的, 当且仅当存在一点 x 使该点到各基站的距离恰好等于给定的 M 个距离值. 若某个除真实关联之外的一致关联存在, 且其交点不是任何真实目标的位置, 则该点称为鬼影目标.

`association_consistent` 用最小二乘解出位置后检查最大残差是否小于 1e−6.

`ghost_target_exists` 的朴素做法是枚举每个基站上 K 个距离的全部排列, 共 (K!)^(M−1) 种 (第一个基站可固定为自然顺序, 因为目标无标签). E3 中 M 最大为 6, K 最大为 6, 朴素枚举不可行. `run_experiments.py` 中的 `_has_ghost_efficient` 采用了剪枝策略: 先枚举前三个基站的所有三元组, 对满足一致性的候选延拓到剩余基站, 每个基站只需在 O(K) 时间内检验候选距离是否落在某条路径上. 该实现与暴力枚举的等价性由 `verify_ghost.py` 验证.

### 5.8 最大似然数据关联

对应论文 Sec. VI-A 与官方 `model.m`. 算法分三步.

**第一步, 枚举可行三元组.** 在前三个基站的距离集合上取笛卡尔积, 共 K³ 个候选. 对每个候选先做三角不等式检验 (两个距离之差不超过对应站间距离加容差 δ, 之和不超过站间距离减容差), 再用高斯–牛顿法解出位置, 残差和超过预算者剔除.

**第二步, 枚举一致的部分匹配.** 每个目标槽位选一个三元组, 且三个基站上用掉的 K 个距离必须恰好等于各自的集合. 实现中对候选按第一站的距离值分组, 并在递归中持续检查已用距离仍是各站集合的子多重集, 以此剪枝.

**第三步, 用匈牙利算法扩展到其余基站.** 对每个部分匹配, 前三个基站的位置已确定; 对第 4 至第 M 个基站, 以"目标当前估计位置到该站的距离"与"该站各候选距离"之差的绝对值构成代价矩阵, 用最优指派配对, 再重新精修位置.

最后按全部 M 个基站的残差总和排序, 取最小者作为最大似然解.

### 5.9 残差预算的设定

论文的 `model.m` 将距离替换为单元中点, 因此即使关联完全正确, 每个基站仍会留下最多 Δd 的残差, 三站合计最多 3Δd.

若严格按论文的 `feasibility_factor = 1.5` 取预算, 即 1.5·M·σ_d = 1.5·M·Δd/2 = 0.75·M·Δd, 这一预算比误差模型本身能达到的水平更紧, 会把几乎所有有效候选排除, 且带宽越大 (Δd 越小) 越严重.

本实现保留该参数的默认值以对应论文, 但在 `max_error` 未显式指定时将实际预算取为 M·Δd, 即 M·2σ_d 再乘 1.5, 使预算与误差模型的量级匹配. 若需复现论文原始的过紧规则, 显式传入 `feasibility_factor=1.5` 即可.

### 6.3 鬼影检测的正控制

E3 的结果是 4500 个几何中 0 个鬼影. 恒返回"无鬼影"的检测器同样会得到零, 因此需要正控制来排除这种可能.

`verify_ghost_positive.py` 为此构造了两个必定存在鬼影的场景, 以及一个负控制.

**正控制一**: 四基站构成正方形 (0,0), (200,0), (0,200), (200,200), 两个目标置于 (60,70) 与 (140,130). 两目标关于方形中心镜像对称, 交换关联后同样能交汇于 (70,60), 该点不是任何真实目标. 暴力法与快速检测器均正确报出该鬼影.

**正控制二**: 三个基站位于半径 150 m 的圆周上, 两个目标关于原点对称置于 (40,25) 与 (−40,−25). 此时两目标到各基站的距离存在对应关系, 交换后同样闭合, 交点落在真实目标位置上. 两种方法均判定存在鬼影.

**负控制**: 30 个随机非对称几何, 两种方法的判定在 30/30 上一致, 均未误报.

正负控制均通过, 说明 E3 的零结果反映的是实际状况, 而非检测器失效.

## 七, 关键指标与实验结果

### 7.1 指标定义

设第 t 个目标的估计位置为 x̂_t, 真实位置为 x_t.

| 指标 | 定义 | 用途 |
|---|---|---|
| 位置误差 | e_t = ‖x̂_t − x_t‖ | 单目标基准 |
| 错误概率 | P(err > t) = #{e_t > t} / 目标总数, t ∈ {1.5, 2, 2.5} m | 对应论文曲线 |
| 均方根误差 | √(mean e_t²) | 连续型总括指标 |
| 均方根误差 (剔除) | 剔除灾难性样本后的均方根误差 | 反映框架正常工作时的精度 |
| 灾难性率 | #{e_t ≥ gate} / 目标总数, gate = max(20Δd, 5 m) | 显式暴露误关联尾部 |
| 中位误差 | median(e_t) | 抗尾部干扰 |
| 95 分位误差 | 误差的 95 分位数 | 尾部刻画 |

**配对方式.** 目标本身无标签, 估计结果与真实值的对应关系未知, 因此先用匈牙利算法求最小总距离的配对, 再统计误差. 这与官方 `diffdist.m` 的做法一致.

**两种均方根误差.** 只报前者会被极少数误关联样本主导——一个 113 m 的误关联足以将 900 个样本的均方根误差由 0.2 m 拉高至 3.8 m; 只报后者则等于隐藏真实失败. 两种指标并列给出.

判据 gate 取 max(20Δd, 5 m) 的依据是: 正确关联下的重建误差应在数倍 Δd 以内, 超出该量级必然是关联错误所致, 而非精度不足.

唯一失分出现在 20 MHz 且 K=6 的两组几何. 该档 Δd = 3.75 m, 带宽最窄时六个目标的距离单元间距最为紧凑, 恒虚警率检测出现漏检, 导致该点的距离均方根误差达 44.50 m——单个漏检即可使距离偏移一个单元以上.

### 7.6 结果五: 消融实验

E5, B=100 MHz, K=4, 每组 100 几何. 通过人为违反正交频假设与改变路径损耗指数, 观察第一阶段的稳定性.

| 跨站路径入带 | 路径损耗指数 | 精确恢复率 |
|---|---|---|
| 否 (论文假设) | 1 | **1.00** |
| 否 | 2 | 0.76 |
| 是 | 1 | **0.00** |
| 是 | 2 | 0.00 |

引入跨站反射后第一阶段直接失效. 机理为: 双站路径的等效距离 (d_u + d_m)/2 落在与自路径不同的距离单元上, 相当于凭空多出 M−1 倍的抽头, "每个基站恰好 K 条路径"这一第二阶段赖以成立的结构被破坏.

论文关于相邻基站使用不同频率的假设对整套框架是必要条件, 不是可有可无的前提.

## 九, 误差分析

本节按对最终定位精度的贡献大小排序, 逐条给出机理, 量级与可核查的证据.

### 9.1 量化误差

**性质**: 主项, 且不可消除.

距离换算取单元中点, 由此产生的误差上界为

```
|d̄ − d| ≤ Δd = c₀/(4B)
```

这是论文式 (8) 给出的界, 也是 7.2 节中剔除后均方根误差紧跟 Δd 的原因. 100 MHz 下 Δd = 0.7495 m, 实测剔除后均方根误差 0.87 m, 中位误差 0.50 m, 量级吻合.

**证据**: E2 六档带宽的剔除后均方根误差与 Δd 呈正比; 图 7 将均方根误差画在 Δd 的 1:1 参考线上, 二者近乎平行.

**结论**: 这一项无法通过改进算法消除, 只能通过增大带宽或增加子载波数压缩.

### 9.2 数据关联错误

**性质**: 尾部主项.

表现为少数目标被放置到区域的另一端, 误差可达 20 至 300 m. E1 中灾难性率为 1.0% 至 1.7%, E2 中为 0.1% 至 2.7%.

**成因**: 最大似然的目标函数是残差之和, 当两个不同关联的残差接近时 (Δd 较大时尤为容易), 会选出错误关联. 该现象源于算法结构.

**证据**: 灾难性率随带宽单调下降 (Δd 变小, 残差区分度变大), 随 K 上升 (候选组合变多).

**缓解方向**: 7.3 节数据显示 K 增大时中位误差几乎不变, 说明错误关联只影响少数样本. 若需进一步压低尾部, 可在关联阶段引入跨帧的时间一致性约束, 这属于论文之外的扩展.

### 9.3 不可行几何

**性质**: 算法明确报告"找不到合法解".

指没有任何关联能同时满足三角不等式与残差预算. E1 与 E2 中各出现 0 至 6 例 (每 300 几何).

**处理方式**: 脚本将其单独计入 `infeasible` 字段, 既不混入误差统计, 也不额外赋值.

E1 中 K=5 与 K=6 各有 4/300, K=2 有 2/300, K=4 为 0/300, 未随 K 单调恶化. 这说明不可行主要来自几何布局本身 (三条圆的残差恰好同时超预算), 而非穷举过程漏解.

**证据**: `verify_enum_strict.py` 交叉验证显示, 快速搜索与暴力枚举的目标函数值之差恒为 0.00e+00, 不存在搜索遗漏真解的情形.

### 9.4 第一阶段漏检

**性质**: 罕见的离散失败.

E4 中 1500 个几何失 2 例 (0.13%), 集中在 20 MHz 且 K=6 的组合.

**成因**: 恒虚警率检测使用全局固定阈值 γ = σ²_h·ln(1/pfa). 当同一基站内 K 个目标的反射强度差异较大时 (α=1 时仍有 10 至 20 倍动态范围), 最弱者可能落在阈值之下.

**证据**: E5 消融中将 α 改为 2 (动态范围约 100 倍) 后, 精确恢复率由 1.00 降至 0.76, 变化方向与机理一致.

**影响**: 单个抽头漏检会使该基站的 K 个距离少一个, 第二阶段将无法组装出正确目标, 误差表现为整目标级别的偏离. 因此该项虽发生率低, 但后果严重.

### 9.5 建模假设被违反

**性质**: 误差的开关, 非渐进性劣化.

E5 结果已列于 7.6 节. 跨站路径入带后, 精确恢复率直接由 1.00 降至 0.00, 无条件归零.

机理已在该节说明: 双站路径产生额外距离单元, 破坏了"每基站恰好 K 条路径"的结构假设, 而第二阶段的三元组枚举与部分匹配约束全部建立在该假设之上.

因此本复现的定量结论仅适用于正交频假设成立的情形. 若实际系统存在严重的跨站干扰, 误差分析中的各项指标均不再适用, 需重新建模.

### 9.6 误差来源小结

| 来源 | 量级 | 是否可消除 | 主要证据 |
|---|---|---|---|
| 量化误差 | 与 Δd 成正比 | 否, 仅能压缩 | 图 7, E2 |
| 关联错误 | 1%–3% 的样本, 误差数十米 | 部分, 需扩展算法 | E1, E2 灾难性计数 |
| 不可行几何 | 0–2% 的几何 | 否, 属几何本质 | E1 的 infeasible 字段 |
| 第一阶段漏检 | 0.13% | 可改善, 需自适应阈值 | E4 的 20 MHz + K=6 |
| 假设违反 | 使全部指标失效 | 否, 属前提条件 | E5 |

## 十一, 局限与后续工作

本节列出当前工作的边界.

### 11.1 当前边界

**其一, 未与论文正式发表的数值表格逐点对齐.**

参考版本为 arXiv v1, IEEE JSAC 正式刊出的版本可能存在数值修订. 本复现验证了趋势与量级, 未做逐格核对.

**其二, 全流程运行于高信噪比条件, 未做信噪比扫描.**

实验中噪声方差固定为 1e-18 (信号级为 1e-14), 对应极高的信噪比. 真实系统中低信噪比是主要矛盾, 本复现的结论不能直接外推到低信噪比场景.

**其三, 官方代码不完整, 第一阶段无法与原作者实现做对比.**

官方仅有 6 个 MATLAB 文件, 无 `main.m`, 无信号级第一阶段. 本复现的第一阶段是按论文公式自行编写的, 虽已通过单元测试与交叉验证, 但缺少与原作者实现的 A/B 对比.

**其四, 未考虑多径干扰与目标间遮挡.**

信道模型仅包含直达反射路径 (以及消融实验中的跨站路径), 未建模墙面对多径, 目标之间的相互遮挡, 以及目标运动带来的多普勒频移.

### 11.2 后续工作

**加做信噪比扫描.** 将噪声方差作为扫描量, 绘制精度随信噪比变化的曲线, 找出框架失效的临界点. 这是最直接, 最有价值的补充.

**引入自适应检测阈值.** 当前恒虚警率检测使用全局阈值, 在目标反射强度差异大时会漏检弱目标. 可考虑按距离单元分组估计噪声, 或采用有序统计恒虚警率检测.

**加入时间一致性约束.** 当前每个时刻独立进行数据关联. 若目标在相邻帧间位置连续, 可将上一帧的估计作为先验, 抑制误关联, 压低头部误差.

**扩展到三维场景.** 当前模型为二维平面. 实际部署中基站与目标均在地面以上, 需要引入高度维度, 此时三边定位需改为多面定位.

**与实测数据对照.** 若能获得软件无线电平台采集的实测数据, 可验证仿真中的建模假设 (尤其是路径损耗指数与跨站干扰) 是否接近实际.
